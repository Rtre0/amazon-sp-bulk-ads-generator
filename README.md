## 1. 能做什么

亚马逊运营最费时的一件事：为几十上百个父体逐个建活动、建广告组、填竞价与预算，
手工做一次要几小时；而**任何一个字段写错，整张 Bulk 表会被亚马逊整体拒绝**。

这个工具把重复劳动变成勾选 + 点一下，并且后来把「先手工导表」这一步也省了：
登录一次赛狐，商品和搜索词报表会自动落到本地，之后直接从本地库选品、投放。

```
离线：赛狐导出 Excel ──▶ 选品 + 调预算 ──▶ 下载 Bulk 表 ──▶ 亚马逊后台上传
在线：赛狐自动同步   ──▶ 本地商品库 / 搜索词 ──▶ 选品分析 ──▶ 导出 Bulk 表 或 直接开广告
```

### 基础能力

| 能力 | 能解决什么 |
| --- | --- |
| 多店铺混合处理 | 一份表里 16+ 个店铺自动分开算，各店铺的价格中位数与预算互不污染 |
| 导出表自动识别 | 不挑列顺序、不挑表头在第几行，赛狐导出的表直接拖进来 |
| 两种预算策略 | 每个活动给一样预算，或按客单价高低自动分配总预算池 |
| 日文品名自动翻中文 | 完全离线的名词词库（461 条），活动名里直接得到干净中文品名；支持热更新与一键重匹配 |
| 生成的表格不会被拒 | 表头与亚马逊官方模板逐字对齐，下载前先在本地自检，字段不合规直接拦下 |

### v2.x 新增能力

| 能力 | 能解决什么 |
| --- | --- |
| 多赛狐账号 | 几个赛狐账号各管各的店铺，同步时不会串号、登录态不会互相覆盖 |
| 本地商品库 + 自动同步 | 不用天天导 Excel；商品、每日搜索词、投放产生 ASIN 自动入库，可定时更新 |
| 自动广告：直接开 | 除导出 Bulk 表外，可以直接在赛狐后台批量建自动广告活动 |
| 手动广告工作台 | 看哪些搜索词 / ASIN 出单，勾选后批量建关键词广告或商品投放广告；匹配类型可多选、竞价可批量调、活动名可逐行改 |
| **广告开启状态** | 商品表里直接标出每个父体「已开启 / 已暂停 / 未开启」，一键筛出还没开广告的商品 |
| 商品图正常显示 | 商品缩略图由后端代理并缓存，不再是一片白块 |
| 活动名自动清洗 | 来源活动名只留「SKU + 产品名」，自动去掉日期、时间、复制后缀等噪音 |
| 数据与账号安全 | 数据库和 Cookie 可一键搬到项目外，仓库里不留任何真实店铺信息 |
| 店铺命名与排序 | 给店铺起好认的名字，所有店铺下拉框按这个名字排序，不再是一串乱序的 `xxx-JP` |
| 平滑批量调价 | 三种调价模式：智能平滑（低价多涨、高价少涨）、线性倍数、平方根阻尼，带实时试算与封顶 |

> 离线链路依然完全零网络依赖；在线同步与直接开广告是可选项，没配登录态也能正常用离线功能。

## 2. 快速开始

**要求**：Python 3.10+，Windows / macOS / Linux 均可，任意现代浏览器。

```bash
git clone https://github.com/Rtre0/amazon-sp-bulk-ads-generator.git
cd amazon-sp-bulk-ads-generator
python -m venv venv
venv\Scripts\activate          # Windows；macOS / Linux 用 source venv/bin/activate
pip install -r requirements.txt
python main.py
```

打开 **<http://127.0.0.1:8000>** 即可。

**Windows 用户**直接双击 `start.bat`：首次自动建环境装依赖，之后双击即开，关掉黑窗口即停服务。
推荐用 **`启动（数据外置）.bat`**，它会把数据库和 Cookie 放到项目外的
`%USERPROFILE%\SellfoxAdsData`，升级或换目录都不丢数据，也绝不会被误传到 GitHub。

> 已经装过旧版的话，先看 [v2.7.0 发版说明](docs/RELEASE_NOTES_v2.7.0.md) 里的升级步骤。

## 3. 怎么用

### 路径 A · 上传 Excel 出表（不用登录，最快）

拖入赛狐导出的 `.xlsx` → 切换店铺核对品名 / 客单价 / 预算 → 设置竞价与预算策略 →
勾选父体 → 下载 Bulk 表 → 到亚马逊后台「批量操作 → 上传」。建议先小批量试传。

> 导出时请勾选：类型、父ASIN、ASIN、MSKU、标题、品名、SKU、店铺、价格、图片。
> 尤其「店铺」和「价格」缺了会影响分组与预算。列顺序、表头在第几行都无所谓。

### 路径 B · 本地商品库 + 自动广告

先在「同步与 Cookie 设置」登录赛狐并同步商品 → 自动广告模块选择**载入本地商品库** →
看商品图、客单价、建议预算和**广告状态** → 勾 **只看未开** 筛出还没投放的父体 →
选择「生成 Bulk 表」或「⚡ 接口直接创建」。

### 路径 C · 搜索词 / 出单 ASIN → 手动广告

点 **查询并同步**（按所选店铺 + 起止日期拉数据，拉完自动查询）→
切换「用户搜索词」或「投放产生 ASIN」维度 → 勾选要投的词 / ASIN →
设置匹配类型、竞价倍数、活动名 → 导出 Bulk 表或直接创建。

> 「投 ASIN」只出现在「投放产生 ASIN」维度；用户搜索词维度的 ASIN 本就是投放对象，
> 再勾一次等于重复投放自己。

### 赛狐账号

一个赛狐账号只能看到自己权限内的店铺；有多个账号时把每个账号加进账号池，
点「全量同步」会逐个账号各拉一遍。推荐「🔑 账号密码登录」（只需人工输一次图形验证码），
也可以临时粘贴 Cookie 或用 Chrome 调试模式抓取。Cookie 一般 **5 天左右过期**，到期重新登录一次。

## 4. 常见问题

<details><summary><b>Q1. 商品图全是白块？</b></summary>

不是图片数据缺失，是浏览器直连亚马逊图床常被拦。现在统一走后端代理 + 缓存，
若仍异常，检查 `data/image_cache/`（或外置数据目录下同名目录）是否可写。

</details>

<details><summary><b>Q2. 「查询并同步」同步了哪段时间？</b></summary>

严格按页面所选的**店铺 + 起止日期**（最多 92 天）。本地已有的日期会自动跳过，
重复点不会重复拉；某一天失败只跳过那天，不影响其它日期。

</details>

<details><summary><b>Q3. 搜索词少了几行 / 某些店铺查不到？</b></summary>

多半是 Cookie 过期（提示「验证失败」或「没有店铺访问权限」），重新登录即可。
多账号时确认当前账号是否有该店铺权限，切换到对应账号再同步。

</details>

<details><summary><b>Q4. 广告状态里的「已暂停」和「未开启」有什么区别？</b></summary>

只有**正在投放（enabled）**的活动才算「已开启」，暂停和归档都不算。
「已暂停」= 以前开过、现在停了；「未开启」= 完全没建过活动。
勾「只看未开」可以把两类一起筛出来。首次查询大店铺约 20 秒，之后有 10 分钟缓存，
可点 `↻` 刷新。

</details>

<details><summary><b>Q5. 「接口直接创建」安全吗？</b></summary>

它会**真的在赛狐后台建活动**，属于写操作。首次请先用单店铺 + 小批量验证，
确认活动名、竞价、预算都符合预期再放量。不确定时先导出 Bulk 表人工检查。

</details>

<details><summary><b>Q6. 上传 Bulk 表被亚马逊拒绝？</b></summary>

先看报告里「错误类型 = 用户输入无效 / 无效实体」的行，其余「未处理 / 警告」是级联提示，
修掉真实错误就会消失。另外确认上传的是**本工具生成的文件**，表头列名一个字都别改。

</details>

<details><summary><b>Q7. 品名识别不准？</b></summary>

在「本地纯净名词词库 → 管理」里补词，再点「🔄 刷新品名匹配」，
不用重新上传 Excel。手动改过名的商品不会被覆盖。

</details>

<details><summary><b>Q8. 端口 8000 被占用？</b></summary>

改 `main.py` 末尾的 `port = 8000` 为其它端口（如 8010）即可。

</details>

## 6. 安全与隐私

- 数据库、Cookie、账号密码、浏览器登录配置**都不进仓库**；推荐用 `启动（数据外置）.bat` 物理隔离。
- 仓库里没有任何真实店铺名、店铺编号或组织名，示例统一用占位名。
- 词库 `data/ja_zh_dict.json` 是业务资产，请勿外传。
